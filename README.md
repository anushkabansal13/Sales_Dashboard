# 📊 Superstore Sales Dashboard (Excel & Power BI)

This project presents a comprehensive sales performance analysis for a fictional superstore using Microsoft Excel and Power BI.
It demonstrates how the same dataset can be used to create dashboards in both tools — highlighting differences in interactivity, usability, and visualization capabilities.

---

## 🧩 Project Overview

This end-to-end analysis uncovers patterns in sales, profit, and discount data, helping stakeholders understand market behavior and optimize business strategies.

The project includes:

Excel Dashboard – Built using Pivot Tables, Charts, and Slicers for a lightweight and interactive solution.

Power BI Dashboard – Enhanced with drill-through analysis, slicers, and KPI cards for a modern and scalable business intelligence experience.

---

## 🎯 Objectives

Analyze sales performance across regions, categories, and segments

Identify top-selling products and peak sales months

Compare Excel vs. Power BI dashboards to showcase visualization capabilities

Derive actionable insights for profit optimization and strategy planning

---

## 📁 Dataset Summary

- Source: Superstore Sales Data [https://www.kaggle.com/datasets/vivek468/superstore-dataset-final]
- Total Records: 9990+  
- Fields Included:
  - Order Date, Region, Category, Sub-Category
  - Sales, Quantity, Discount, Profit, Customer Name

---

## 🛠️ Tools Used

Microsoft Excel – Pivot Tables, Pivot Charts, Slicers, Conditional Formatting

Power BI – DAX Measures, Interactive Filters, KPI Cards, Drilldowns
---

## 📈 Excel Dashboard Features

- Monthly Sales Trend
- Top 5 Products by Sales

## ⚖️ Excel vs. Power BI – Comparison

| Feature              | Excel Dashboard     | Power BI Dashboard                    |
| -------------------- | ------------------- | ------------------------------------- |
| **Ease of Creation** | Quick & lightweight | Requires setup but scalable           |
| **Interactivity**    | Slicers & filters   | Drilldowns, cross-filtering, tooltips |
| **Visual Appeal**    | Traditional charts  | Modern, professional visuals          |
| **Scalability**      | Best for small data | Handles larger datasets easily        |
| **Sharing**          | File-based sharing  | Can publish to Power BI Service (web) |
