# 📊 Superstore Sales Dashboard (Excel)

This project presents a comprehensive sales performance analysis for a fictional superstore using **Microsoft Excel**. It includes interactive dashboards built with pivot tables, charts, and slicers to help identify key trends, product insights, and regional performance metrics.

---

## 🧩 Project Overview

This end-to-end analysis aims to uncover patterns in sales, profit, and discount data, helping stakeholders understand market behavior and optimize strategies. The dashboard focuses on KPI tracking and data visualization to support decision-making.

---

## 🎯 Objectives

- Analyze sales performance across different regions and products
- Identify top-selling products and peak sales periods
- Provide visual summaries through Excel dashboards
- Derive insights using KPIs and interactive filtering

---

## 📁 Dataset Summary

- Source: Superstore Sales Data [https://www.kaggle.com/datasets/vivek468/superstore-dataset-final]
- Total Records: 9990+  
- Fields Included:
  - Order Date, Region, Category, Sub-Category
  - Sales, Quantity, Discount, Profit, Customer Name

---

## 🛠️ Tools Used

- **Microsoft Excel**  
  - Pivot Tables  
  - Pivot Charts  
  - Slicers & Filters  
  - Conditional Formatting

---

## 📈 Excel Dashboard Features

- Monthly Sales Trend
- Top 5 Products by Sales
- Region-wise Sales & Profit Analysis
- Profit Margin Visualization
- Interactive filters by Region and Product Category
